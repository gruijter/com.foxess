FoxCloud를 통해 Fox ESS 장치를 Homey에 연결하세요. FoxCloud는 5분마다 업데이트됩니다.

지원 장치:
- 인버터: 태양광 전력과 발전량, 인버터 출력, 비상 전원(EPS) 전력, 상태 및 활성 고장. 전력망 송전 한도를 설정할 수 있습니다.
- 배터리: 충전 상태와 건강 상태, 전력, 충전 및 방전 에너지, 온도와 사이클. Homey가 정한 전력으로 배터리를 충전하고 방전할 수 있으며, 작동 모드와 SoC 한도를 설정할 수 있습니다.
- 전력망 미터: 상별 전력, 수전 및 송전 에너지, 전압, 주파수, 가정 소비량.
- 히트펌프(베타): 작동 모드와 온수 설정, 현재는 읽기 전용.

요구 사항: 설비가 FoxCloud 계정에 등록되어 있어야 합니다. FoxCloud의 사용자 프로필 > API 관리에서 API 키를 만들고, 장치를 추가할 때 입력하세요.

⚠️ 다른 에너지 관리자: FoxCloud, 설치 업체, 에너지 공급업체(VPP) 또는 다른 앱이 Homey로부터 배터리와 송전 한도의 제어권을 되가져갈 수 있습니다. 이 경우 Homey는 '제어 덮어씀'을 표시하고, 사용자가 다시 설정을 변경할 때까지 제어를 그쪽에 맡깁니다. Homey에서 배터리를 제어하려면 다른 어떤 것도 배터리를 제어하지 않도록 하세요(설치 업체 또는 에너지 공급업체에 문의).
